# Topology

`pccx-v002` is the reusable PCCX v002 IP-core package repository.

The repository is organized by domain:

- `LLM`
- `Vision`
- `Voice`
- `common`

Repository-level docs, tests, and compatibility files live in:

- `docs`
- `tests`
- `compatibility`

The compatibility source for this package is
`compatibility/v002-contract.yaml`.
