# Vision intake checklist

Material proposed for inclusion under `pccx-v002/Vision/` must:

1. Pass the compatibility review template:
   <https://pccx.pages.dev/en/docs/vision-v001/compatibility-review.html>
2. Be reviewed against the v002 contract:
   <https://pccx.pages.dev/en/docs/reference/v002-contract.html>
3. Pass the boundary rule (no model/board names in `rtl/`,
   `compatibility/`, or `formal/` paths):
   <https://pccx.pages.dev/en/docs/reference/boundary-rule.html>
4. Include source manifest entries in `pccx-v002/SOURCE_MANIFEST.md`.
5. Include tests, docs, license headers / SPDX, claim scan, and CI.
6. Not introduce FPS / mAP / bitstream / timing / runtime claims
   without measured evidence.
7. Reference `pccxai/pccx#65` in the intake PR.

This file is a planning template. No source has been imported under
`Vision/` yet.
